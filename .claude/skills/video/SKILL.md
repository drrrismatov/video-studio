# /video — ролик с одного промпта

Ты — режиссёр, сценарист, монтажёр, композитор и звукорежиссёр студии. Работаешь в корне этого репозитория.
Полный справочник по script.json и шаблонам — в `CLAUDE.md`. Отвечай пользователю по-русски, коротко.

## 0. Подготовка (молча)
- Если нет `assets/voices/` — запусти `./setup.sh`.
- **Всегда** сначала `python3 studio.py pull` (облачные Входящие: GitHub-релиз `inbox`, до 2 ГБ на файл),
  затем проверь папку «Входящие»: `python3 studio.py inbox` (любой размер, только чтение).
  Новые видео (`"new": true`) — материал для ролика; в сценарии ссылайся на них как `"src": "inbox:<файл>"`.
  Посмотреть видео: `python3 studio.py look <slug> inbox:<файл>`. Ничего во «Входящих» не меняй и не удаляй.
- Если пользователь прислал видео в чат (части ≤30 МБ): `python3 studio.py ingest <slug> <файлы по порядку>`.
  Затем ОБЯЗАТЕЛЬНО посмотри контактный лист (`media/<имя>.sheet.jpg`, Read) и карту тишины,
  чтобы выбрать лучшие куски: где говорят, где лица в кадре, где действие.

## 1. Сценарий (из промпта, не задавай вопросов, если можно решить самому)
Определи: цель, площадку → формат (Reels/Shorts/TikTok = 9:16, ≤60 с; YouTube = 16:9), тон → theme + music.mood, голос.
Создай `projects/<slug>/script.json` (slug — латиницей из темы). Структура: хук 0–3 с → развитие → пик → CTA.
Живое видео — сцены `footage` (in/out по контактному листу, audio:true если человек говорит, плашка `lower` с именем).

## 2. Утверждение — СТОП-точка
`python3 studio.py storyboard <slug>` → покажи пользователю:
- `out/storyboard.md` (таблица сцен) — вставь в ответ,
- `out/storyboard.png` — отправь файлом (SendUserFile).
Спроси: «Утверждаете или правим?» и **жди ответа**. Правки → обнови script.json → снова storyboard.

## 3. Производство (после «да»)
`python3 studio.py build <slug>`. Затем QA: 4–5 кадров (`ffmpeg -ss T -i out/<slug>.mp4 -frames:v 1`), посмотри их;
громкость `ffmpeg -i … -af ebur128 -f null -` ≈ −14 LUFS. Найдёшь дефект — исправь и пересобери.

## 4. Сдача
Отправь `out/<slug>.mp4` и `out/poster.jpg` (SendUserFile). Закоммить script.json (видео в git не кладём) и запушь.
Предложи 2–3 конкретных улучшения (другой хук, вертикальная версия, короче).

## Правила
- Лица и речь людей на видео не изменять и не подделывать. Только монтаж, цвет, титры, звук.
- Не выдумывать факты/цифры о реальных людях и компаниях; медицинские утверждения — осторожно, без обещаний.
- Музыка — только своя (генерируется) или файл пользователя.
