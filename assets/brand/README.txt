Video Studio — ярлык на рабочий стол (открывает https://claude.ai/code)

WINDOWS: распакуйте архив и дважды щёлкните Install-Windows.bat
  (если появится синее окно «Windows защитил компьютер» — «Подробнее» → «Выполнить в любом случае»).

MAC: распакуйте архив, щёлкните ПРАВОЙ кнопкой по Install-Mac.command → «Открыть» → «Открыть».

В студии: New session → среда creative-studio → репозиторий video-studio → /video <ваша идея>
Репозиторий: https://github.com/drrrismatov/video-studio
