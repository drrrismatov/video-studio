# AI Video Studio
Один промпт → сценарий → одобрение → готовый ролик (голос, музыка, монтаж, эффекты).
См. CLAUDE.md. Быстрый старт: `python3 studio.py build demo`.
Зависимости: python3 (numpy, scipy, pillow, piper-tts), node + playwright, ffmpeg.
Голоса: assets/voices (скачиваются с релизов k2-fsa/sherpa-onnx tts-models).
