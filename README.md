# 🎬 AI Video Studio

**Один промпт → сценарий → ваше «да» → готовый ролик.** Голос, музыка, монтаж, переходы, титры, сведение.

```
/video Ролик для Reels про утреннюю зарядку, 30 секунд, бодро
```

| Этап | Что делает студия |
|---|---|
| Сценарий | хук, структура, закадр, раскадровка — на утверждение |
| Видео | 10 шаблонов моушн-графики + ваше живое видео (лица без изменений) |
| Звук | нейроголос (3 русских голоса), своя музыка под сцены, SFX, −14 LUFS |
| Монтаж | 20+ переходов, цветокор, зерно, субтитры, плашки с именами |
| Форматы | 16:9 · 9:16 · 1:1 · 4:5, 1080p 30fps |

Установка: `./setup.sh` (нужны python3, node, ffmpeg). Регламент: `CLAUDE.md`.
Ваше видео: части ≤30 МБ → `python3 studio.py ingest <проект> часть1.mp4 часть2.mp4`.
